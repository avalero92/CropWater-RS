# Methodology

The authoritative scientific description for CropWater-RS v2.0.0 is available in [Scientific Methodology, Algorithms and Reproducibility](../SCIENTIFIC_METHODOLOGY.md).

That document covers Sentinel-2 L2A processing, SCL masking, NDVI quality control and daily reconstruction, adapted QUANT phenology, the independent sowing-date assignment options, crop coefficients, ETc, simplified net IWR and reproducibility.
