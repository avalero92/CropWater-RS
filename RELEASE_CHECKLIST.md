# Public release checklist

Before final archival publication:

- [ ] Test the application in a clean environment.
- [ ] Test manual and attribute-based crop labelling.
- [ ] Test CDSE using your own credentials.
- [ ] Test Linear, Whittaker, Savitzky-Golay and Kalman processing.
- [ ] Test QUANT on multiple parcels.
- [ ] Test Kc, ETc/CWR and IWR.
- [ ] Test CSV and GeoPackage exports.
- [ ] Complete affiliation, email and ORCID if desired.
- [x] Repository metadata points to `https://github.com/avalero92/CropWater-RS`.
- [x] Final GitHub URL added to `software_metadata.json`.
- [ ] Create GitHub release/tag `v1.0.0`.
- [ ] Archive the release in Zenodo.
- [ ] Add the assigned DOI to README, CITATION.cff and software metadata.
- [ ] Never upload CDSE Client Secrets.
